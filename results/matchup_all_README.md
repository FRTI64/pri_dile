## 说明

- 加权分数是“按测试集家族分布抽样的期望分”，不是重新抽取 299 人赛场的单次结果；与 `ipd suite` 的采样结果会有小幅随机差异。
- `matchup_all.json` 中保存了每个测试集的逐对手归一化权重，便于复核。
- 对手库包含 158 类；`plus` / `smart` 家族也会参与对应测试集的加权。
